# Intake Questionnaire Draft

The questionnaire should guide the user from a broad industry idea into a research-ready request.

## Section 1: Scope

1. What industry, market, or sector do you want to research?
2. What final product, service, technology, or value chain should the map explain?
3. Which geography should the research prioritize?
4. Should the engine include global companies, local companies, or both?

## Section 2: Research Goal

1. Are you trying to find suppliers, customers, competitors, partners, or all of them?
2. Are you primarily looking for publicly traded companies?
3. Are private companies, subsidiaries, or state-owned companies relevant?
4. Are you looking for investment targets, strategic suppliers, acquisition targets, or general ecosystem understanding?

## Section 3: Depth

1. Should the chart be high-level, standard, or deep?
2. Should the engine include raw materials and upstream inputs?
3. Should the engine include distribution, sales channels, and end customers?
4. Should the engine include equipment, software, services, and enabling infrastructure?

## Section 4: Evidence Strictness

1. Should relationships require direct proof, or are strong industry inferences acceptable?
2. Which source types should be preferred?
3. Should the engine flag uncertain relationships instead of hiding them?
4. Should the engine include older sources if recent evidence is limited?

## Section 5: Company Intelligence

1. Which company metrics matter most?
2. Should the engine estimate revenue purity?
3. Should the engine estimate market share?
4. Should the engine flag customer concentration?
5. Should the engine flag geopolitical, regulatory, or supply disruption risk?

## Section 6: User Seeds

1. Are there known companies that must be included?
2. Are there known companies that should be excluded?
3. Are there known products, components, or technical terms to include in searches?
4. Are there source links the engine should treat as starting evidence?

## Section 7: Output

1. Should the output chart be optimized for screen viewing, presentation, or report export?
2. Should the chart show companies, process categories, or both?
3. Should the chart include confidence badges?
4. Should the chart include deal and evidence badges?
5. Which data formats should be exported?
